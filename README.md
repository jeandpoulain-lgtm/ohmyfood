# Ohmyfood — Réservation de menus en ligne

## 📌 À propos
Ce projet fait partie du parcours **Intégrateur Web** d'OpenClassrooms. L'objectif était de développer un site "Mobile-First" répertoriant les menus de restaurants gastronomiques parisiens, en mettant l'accent sur les animations CSS avancées et l'architecture Sass.

## 🚀 Fonctionnalités
- Intégration en approche **Mobile-First**, entièrement responsive (mobile, tablette, desktop).
- Animations CSS fluides et modernes sans JavaScript (loader de chargement, apparition progressive des plats, coche de sélection animée, bouton "J'aime" progressif).
- Architecture CSS modulaire et maintenable organisée avec **Sass** (variables, mixins, partials).

## 🛠️ Stack technique
- **HTML5**
- **CSS3 / Sass (SCSS)**
- **Git & GitHub**
